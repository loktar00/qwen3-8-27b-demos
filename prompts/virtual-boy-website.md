# Virtual Boy Microsite

Demo: [virtual-boy-website](../virtual-boy-website/) (BF16), [nvfp4-virtual-boy-website](../nvfp4-virtual-boy-website/) (NVFP4), [q8-virtual-boy-website-2](../q8-virtual-boy-website-2/) (Q8)

Your team has been contracted on a $500,000 project to create a premium retro technology microsite for the Nintendo Virtual Boy.

You have been asked to provide only a single HTML page because this will be used as a static interactive demo. The final result should feel like an immersive retro hardware website, not a generic product page. It should be visually striking, strange, nostalgic, and highly polished, with a strong sense of 1990s experimental gaming hardware, red monochrome graphics, early VR ambition, and collector-focused energy.

You can use anything from CDNs to include fonts, icons, images, CSS, JavaScript, Three.js, animation libraries, or retro-style effects. The page should have major visual impact and feel like a high-end collector and gaming history microsite. It should be modern in execution but strongly inspired by the Virtual Boys black and red visual identity, tabletop headset form factor, 90s tech ads, wireframe graphics, scanlines, and early 3D gaming promise.

The design should use a bold retro visual language with black, deep red, bright red, dark gray, subtle crimson glows, monochrome pixel textures, wireframe grids, and sharp contrast. Typography should feel technical, slightly futuristic, and 90s-inspired. The overall mood should communicate failed ambition, strange innovation, rare hardware, experimental 3D, and the feeling of discovering a weird artifact from gaming history.

The page must include a large interactive hero section built with Three.js. This is one of the main requirements. The hero should create a strong "wow" moment. It should feature a stylized 3D scene inspired by the Virtual Boy, such as a floating red wireframe headset, a rotating tabletop console silhouette, a red monochrome 3D grid, floating game cartridges, pixel particles, parallax depth layers, or a simulated stereoscopic red display. The hero should respond subtly to mouse movement and feel alive. It should be smooth and visually impressive without being chaotic or hard to use.

Overlay the hero with a powerful title treatment for Nintendo Virtual Boy, a short dramatic tagline, and clear calls to action such as "Explore the Hardware" and "Enter Red Space." The text should remain readable over the interactive Three.js background.

Build a complete single-page retro hardware website that includes:

A top navigation/header with a sharp retro-tech title treatment, navigation links, and a call-to-action button.

A cinematic hero section with the interactive Three.js experience, title, tagline, and CTA buttons.

A hardware story section with polished editorial copy explaining the Virtual Boy as a bold and unusual experiment in gaming history. The writing should feel premium and historically aware, while still capturing the weird charm of the device.

A product overview section that presents the Virtual Boy as if it were being reintroduced for collectors. Include the headset, tabletop stand, controller, cartridges, red monochrome display, 3D effect, and unusual design.

A feature section using stylized cards or panels for:
- Red monochrome display
- Stereoscopic 3D gameplay
- Tabletop headset design
- Unique dual-grip controller
- Cartridge-based games
- Portable but not handheld form factor
- Experimental 1990s VR concept
- Collector rarity

A specs section with a clean table or grid. Include fictional or historically inspired fields such as display type, color palette, processor, controller type, game format, release era, visual style, power source, player mode, and collector status. Make the table look polished and credible.

A games library section showing several Virtual Boy games as collector cards. Include titles such as Marios Tennis, Red Alarm, Wario Land, Teleroboxer, Galactic Pinball, and Vertical Force. Each card should include genre, rarity, short description, and a red monochrome thumbnail-style visual. Use original placeholder art, geometric shapes, pixel patterns, or stylized silhouettes rather than official box art.

A "Why It Failed, Why It Matters" section. This should be honest but respectful. Explain that the Virtual Boy was commercially unsuccessful, uncomfortable for some players, limited by its monochrome display, and ahead of its time in concept. Then explain why it remains fascinating: bold experimentation, early 3D ambition, unique industrial design, and collector appeal.

A timeline section showing key fictionalized or historical-style milestones, such as concept development, launch, public reaction, short market life, cult status, and modern collector rediscovery. This should feel like a premium editorial layout.

A visual experience section that simulates the Virtual Boys red display. Create a faux game viewport with animated red wireframe terrain, simple moving sprites, scanlines, depth layers, or parallax pixels. This can be done with Canvas, CSS, or Three.js. It should look like a tiny playable-looking demo, but it does not need to be a real game.

A collector market section with fictional marketplace-style cards showing condition, completeness, price range, rarity, and notes. Include examples like loose console, complete-in-box unit, sealed game, controller-only, and full collector bundle. This should test practical e-commerce-style layout inside a retro tech site.

A comparison section comparing the Virtual Boy to other gaming hardware categories, such as handheld consoles, home consoles, arcade cabinets, and modern VR headsets. Include columns such as Era, Display, Portability, 3D Support, Comfort, Game Library, Legacy, and Collector Appeal.

A quote or legacy section with a few short statements about the Virtual Boys place in gaming history. Keep it concise, nostalgic, and slightly dramatic.

A footer with retro-style links, collector resources, fictional museum/archive links, social links, and legal/disclaimer-style text.

The website should have subtle scroll animations, glowing red hover effects, scanline overlays, pixel noise, animated grids, tasteful parallax, smooth transitions, and strong visual continuity from section to section. The page should feel like a carefully directed retro-tech experience, not a template assembled from random parts.

The final result must be a single self-contained HTML file. It should include all HTML, CSS, and JavaScript in one file. It should work by opening the file directly in a browser. Do not require a build step.

Avoid copying official Nintendo artwork, official logos, exact game box art, or trademarked visual assets. Use text treatment, geometric shapes, silhouettes, red wireframes, pixel patterns, and original visual elements inspired by 1990s red monochrome gaming hardware instead.

You are the best retro technology web design agency in the Western Hemisphere, some say the world. You create immersive digital experiences that make forgotten hardware feel legendary. Your work is known for atmosphere, polish, interactivity, nostalgia, and technical credibility. This microsite should feel like a premium collector archive for one of the strangest and most fascinating gaming systems ever released.
