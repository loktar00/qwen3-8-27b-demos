# Helvetica Transit Archive

Demo: [website-swiss](../website-swiss/)

Create one complete, self-contained HTML file for HELVETICA TRANSIT ARCHIVE, a fictional international museum collection devoted to public transportation maps, signs, tickets, clocks, and information systems.

Use a rigorous minimalist Swiss International Typographic Style. Build on a precise modular grid, generous white space, black typography, a disciplined red accent, mathematical alignment, tiny captions, large grotesk headings, crisp rules, and carefully controlled asymmetry. The design should feel museum-grade and contemporary, not like a generic startup. Avoid decorative gradients, shadows, rounded card collections, and visual clutter.

Include a typographic hero with a live station clock, collection introduction, filterable-looking archive grid for eight objects, a large transit-map study generated with SVG, a timeline of information design, a featured designer essay, a clean comparison/specification table, exhibition details, and a restrained footer. All visuals must be original CSS/SVG/Canvas constructions; do not hotlink official transit artwork or images.

Use refined motion: grid elements revealing on scroll, map routes tracing into place, the clock moving accurately, subtle red focus states, and precise hover transformations. Preserve excellent hierarchy, accessibility, keyboard focus, and mobile responsiveness. The file must open directly in Chrome with no build tools or other assets. Google Fonts or a pinned CDN may be used only if necessary. Return only the complete HTML document inside one html code block.
