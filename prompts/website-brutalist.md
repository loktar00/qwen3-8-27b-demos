# Concrete Index

Demo: [website-brutalist](../website-brutalist/)

Create one complete, self-contained HTML file for a premium brutalist website called CONCRETE INDEX, an independent archive of remarkable civic architecture and public infrastructure.

Make it feel intentionally raw, confrontational, and highly art-directed rather than unfinished. Use oversized condensed typography, hard black rules, exposed grid lines, asymmetric columns, abrupt blocks of safety orange and electric blue, monospace metadata, numbered records, severe spacing changes, and visible structural labels. Avoid rounded cards, soft gradients, glassmorphism, generic SaaS layouts, and stock-dashboard aesthetics.

Include a forceful full-screen hero, a scrolling index of six fictional structures, an editorial feature about a monumental coastal water plant, a dense facts/specifications table, a fragmented manifesto, a horizontal archive strip, and a footer that resembles construction documentation. Generate all imagery in-page with CSS, SVG, or Canvas: stark geometric building silhouettes, site-plan lines, registration marks, concrete grain, measurement arrows, and animated diagram fragments. Do not hotlink images.

Add purposeful motion: a ticking issue counter, subtle parallax in the hero plans, a continuously moving record ticker, animated crosshair/measurement overlays, and hard-cut hover transitions. The page must remain readable, responsive, and polished on desktop and mobile. No build tools or additional files. Pinned CDNs and Google Fonts are allowed only if genuinely helpful. Return only the complete HTML document inside one html code block.
