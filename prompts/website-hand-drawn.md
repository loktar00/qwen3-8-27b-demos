# The Moss Notebook

Demo: [website-hand-drawn](../website-hand-drawn/) (BF16), [nvfp4-website-hand-drawn](../nvfp4-website-hand-drawn/) (NVFP4), [q8-website-hand-drawn](../q8-website-hand-drawn/) (Q8)

Create one complete, self-contained HTML file for THE MOSS NOTEBOOK, a naturalist's hand-drawn field journal documenting a year of forests, fungi, streams, birds, and tiny discoveries.

Make the whole site feel illustrated by hand on cream sketchbook paper. Use ink outlines, pencil shading, watercolor washes, uneven borders, taped notes, marginal arrows, handwritten annotations, specimen labels, small doodles, and imperfect dividers. Keep the visual system coherent and beautiful, not childish. Typography should combine a readable editorial serif with convincing handwritten accents. Avoid polished corporate cards, glossy effects, and external photographs.

Include a welcoming cover-like hero, seasonal field entries, an illustrated habitat map, seven specimen notes, a long-form featured observation, a compact weather ledger, soundscape descriptions, a supplies list, an about-the-naturalist section, and a footer styled like the back page of a notebook. Generate all drawings inside the page with SVG, Canvas, or CSS: leaves, mushrooms, feathers, topographic contours, insects, and water ripples. Do not hotlink images.

Animate sparingly and organically: a sketched bird crossing the margin, gently swaying stems, ink lines drawing themselves, pinned notes lifting on hover, and watercolor blooms shifting almost imperceptibly. Ensure responsive layout, readable text, reduced-motion support, and direct Chrome operation with no build step or extra files. Return only the complete HTML document inside one html code block.
