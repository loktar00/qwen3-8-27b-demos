# Ink Weather

Demo: [website-risograph](../website-risograph/)

Create one complete, self-contained HTML file for INK WEATHER, a joyful independent print fair and risograph studio festival.

Use a richly layered risograph aesthetic: warm off-white paper, fluorescent coral, cobalt, sunflower yellow, mint, and dense black inks; visibly imperfect color registration; halftone dots; rough paper grain; overprinted translucent shapes; hand-cut collage edges; limited spot-color illustrations; playful editorial typography. The result should feel tactile and handmade while still being a sophisticated, usable modern website. Do not use generic cards, glossy gradients, or photoreal stock imagery.

Include an expressive hero poster, festival date/location, an animated ink-layer visual, a schedule for workshops and talks, profiles for six fictional printers, a map-like venue section, a limited-edition poster shop, attendee quotes, an FAQ, newsletter signup, and a lively footer. Create every visual with CSS, SVG, or Canvas; never hotlink an image. Use overlapping ink layers and slight offsets deliberately without making text hard to read.

Add subtle motion such as drifting paper scraps, cycling spot-color separations, a slow print-roller animation, hover misregistration, and scroll reveals. Make the page responsive, accessible, and fully functional when opened directly in Chrome. No build tools or separate files. Pinned CDNs and Google Fonts are allowed only when useful. Return only the complete HTML document inside one html code block.
