# /dev/null ZINE

Demo: [website-terminal-zine](../website-terminal-zine/)

Create one complete, self-contained HTML file for /dev/null ZINE, a fictional underground hacker culture zine delivered entirely as a green-phosphor CRT terminal.

Commit fully to a monochrome green-phosphor terminal aesthetic: black background, glowing green monospace text, visible CRT scanlines, subtle screen curvature and vignette, flickering cursor blocks, ASCII/box-drawing borders, and a faint phosphor bloom around bright text. Everything, including headings and navigation, must read as terminal output rather than a styled "dark mode" website. Avoid modern sans-serif typography, colorful accents, rounded UI elements, and conventional web chrome (no traditional navbar, cards, or buttons with shadows).

Include a boot-sequence-style intro, a directory-listing-style article index for six zine issues, a full featured article rendered as terminal text with ASCII-art illustrations, a "man page" style contributor bios section, a command-line-styled contact/subscribe prompt, and a footer formatted like a system status line. Generate all visuals in-page with CSS, SVG, or Canvas: ASCII art, box-drawing dividers, scanline/CRT overlays, and a blinking cursor. Do not hotlink images.

Add purposeful motion: a typewriter/boot-sequence text reveal on load, a continuously blinking cursor, subtle CRT flicker and scanline drift, and terminal-style hover states (inverted color blocks) on interactive text. The page must remain readable, responsive, and polished on desktop and mobile despite the terminal conceit. No build tools or additional files. Pinned CDNs and Google Fonts are allowed only if genuinely helpful (a monospace font is expected). Return only the complete HTML document inside one html code block.
